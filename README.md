# AI Fraud Detection System 🚀

An AI-based Fraud Detection System built using Machine Learning and Streamlit.

## 🔍 Features
- Fraud probability prediction
- Karnataka city & pincode based detection
- Interactive dashboard with graphs
- Fraud score & risk classification (SAFE / REVIEW / BLOCK)

## 🛠 Tech Stack
- Python
- Scikit-Learn
- Pandas
- Streamlit
- Plotly

## 📊 How It Works
The model predicts fraud probability based on:
- Transaction Amount
- City Code
- Transaction Time (Hour)

If:
- Probability >= 70% → BLOCK
- 40% - 69% → REVIEW
- < 40% → SAFE
